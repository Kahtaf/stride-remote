# Changelog

## 1.0.5 — 2026-10-31

First public release.

- Standalone Wear OS control for classic FE00 WalkingPad devices, initially tested with Galaxy Watch8 and A1 Pro.
- Confirmed Start, 0.1 km/h speed adjustment, pinned Stop, live session steps/distance/time, and Manual/Auto controls.
- Persistent connection notification and watch-face shortcut.
- New adaptive walking/treadmill launcher icon and matching monochrome icon.
- Discard expired Auto-mode commands after a scheduling delay.
- Preserve the requested action after granting Bluetooth permission.
- Portable installation and version-aware release scripts; formatted Java; CI, contribution and security documentation.

## Earlier personal builds

1.0.4 added session metrics and mode controls. 1.0.3 corrected raw-state gating for Start and speed controls. 1.0.2 added the ongoing activity; 1.0.1 reduced interface text. Those builds were shared locally before the public repository existed.
