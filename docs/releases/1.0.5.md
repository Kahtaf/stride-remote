First public release of **Stride Remote**, a standalone Wear OS controller for classic Bluetooth WalkingPad devices.

### Install

Download **`stride-remote-1.0.5.apk`** below and sideload it onto your watch. No phone companion or account is required. [Installation instructions](https://github.com/Kahtaf/stride-remote/blob/v1.0.5/INSTALL.md) include wireless ADB pairing and a small-chunk transfer fallback.

The watch needs Android API 33+ (Wear OS 4+) and Bluetooth LE. Initial hardware testing uses **Galaxy Watch8 + WalkingPad A1 Pro WPA1F Pro**. Other models are unverified; this release supports the classic **FE00/FE01/FE02** protocol, not the physical remote's proprietary 2.4 GHz signal or every WalkingPad protocol.

### Features

- Start with a second-tap confirmation, 0.1 km/h speed adjustment, and pinned Stop.
- Live pad-reported session steps, distance and elapsed time.
- Confirmed Manual/Auto controls, enabled while stopped.
- Persistent connection notification, Stop action and watch-face return shortcut.
- New adaptive walking/treadmill icon and matching monochrome icon.
- No Internet permission, analytics, account or cloud relay.

This release also discards delayed Auto-mode commands, preserves the requested action after Bluetooth permission is granted, and includes portable installation/build scripts, CI, license attribution and contributor documentation.

### Verification and limits

24 unit tests, Android lint, formatting, clean-source build, round Wear OS emulator UI checks and exact signed-APK checks passed. The APK excludes the simulator and is signed with the same certificate as earlier personal builds, allowing upgrades in place. The signed release also installs and launches on the emulator. Hardware reports are still needed for the session/mode UI and additional models; emulator results do not establish treadmill compatibility.

Stop the pad before installing. Keep its physical power/stop control available: Bluetooth loss, a killed process or a powered-off watch cannot deliver Stop. This app is not an emergency stop or safety device.

### Integrity

`SHA256SUMS` covers the APK and can be checked with `sha256sum -c SHA256SUMS` or `shasum -a 256 -c SHA256SUMS` after downloading both assets into the same folder.
